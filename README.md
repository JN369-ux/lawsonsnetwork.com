# lawsonsnetwork.com

The Lawsons Network website: plain HTML, CSS and JavaScript in `site/`.

**Live:** GoDaddy cPanel hosting. cPanel → Git Version Control pulls this repository and `.cpanel.yml` copies `site/` into `public_html`.
**Enquiry form:** posts to https://lawsons-network.pages.dev/api/enquiry (Cloudflare Pages Function), which emails jn@lawsonsnetwork.com.
